# Gemini pipeline archive (2026-07-29)

One-off scripts and working files from the Gemini-authored pass on `street-guide.html`.
Kept as a record of how that version was produced; nothing here is referenced by any page.

- `*.py` — 35 single-use build/patch scripts.
- `images/` — the local image set that pass assembled. Mixed provenance, which is why it
  was retired: Met open-access originals (`img_001`–`img_014`) sit alongside modern stock
  photographs (Moscow, Berlin, Toronto, a concert crowd) and 1860s studio portraits, none
  of which are street photographs. Also holds the discarded neon "TENSION VECTOR"
  annotation PNGs and pipeline screenshots.
- `met_20_dataset.json` — Met image/collection/title mapping used by those scripts.
- `inspect_*.jpg`, `test*.jpg` — scratch files.

Safe to delete. Retained only so the provenance of the retired version stays checkable.
